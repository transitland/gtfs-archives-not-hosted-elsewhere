# gtfs-archives-not-hosted-elsewhere

This was a repo where the Transitland team would publicly host static GTFS feed archive emailed to us by agencies or created by us.

There are challenges to managing files in git repositories, so we now host these in a cloud storage bucket instead and have retired this repository.

# Where to find the files previously hosted in this repository

See [Transitland website's feed listings](https://www.transit.land/feeds) or query the [Transitland REST feed endpoint](https://www.transit.land/documentation/rest-api/feeds)

# How to submit a new feed archive:

E-mail hello@transit.land. Please include:

- Your name
- Your affiliation: whether you work for a transit agency, are a part of a local civic group, or have another sort of interest in the feed in question.

Please attach the feed, if it's under 7 MB. If it's larger, don't attach it, and we'll send you alternative instructions for how to upload your file.
